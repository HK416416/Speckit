# 投机推理方向（方向一）全部要求

## 一、论文研读要求
需完成以下 4 篇投机推理方向论文的阅读学习：
1. *Fast Inference from Transformers via Speculative Decoding*
2. *SpecInfer: Accelerating Generative LLM Serving with Speculative Inference and Token Tree Verification*
3. *EAGLE-2: Faster Inference of Language Models with Dynamic Draft Trees*
4. *DFlash: Block Diffusion for Flash Speculative Decoding*

## 二、系统实践：vLLM 特性性能实验（必做）
### 必测核心特性与启动参数
以下 4 项特性为全员必做实验内容，其中投机推理为本方向核心特性：
| 特性 | 对应启动参数 |
| ---- | ------------ |
| 前缀缓存 | `--enable-prefix-caching` |
| 分块预填充（Chunked Prefill） | `--enable-chunked-prefill` |
| 最大并发序列数（并行度） | `--max-num-seqs` |
| 投机推理 | `--speculative-config` |

> 补充：其余 vLLM 特性可查阅官方文档，自行选择拓展实验。

### 核心观测指标
实验过程中需重点观测三类性能指标：
- TTFT（首 Token 生成时间）
- TPOT（单 Token 生成时间）
- 系统吞吐量

### 实验汇报要求
最终汇报需覆盖以下三点内容：
1. 环境配置：实验使用的显卡型号、vLLM 版本
2. 实验设计：实验方案逻辑、基线设置、选用的测试数据集
3. 特性-指标关联：分析各特性分别影响哪些性能指标，以及对应的影响机制
